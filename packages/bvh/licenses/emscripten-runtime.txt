Emscripten runtime code inside the tinybvh WebAssembly module
==============================================================

The .wasm in src/tinybvh-wasm.ts is tinybvh (licenses/tinybvh.txt) plus a small
part of the runtime that Emscripten 6.0.13 links into every standalone module:

- Emscripten's own system code (startup, stack helpers, sbrk): MIT or
  University of Illinois/NCSA, at the user's choice; the MIT text is below.
- musl libc (printf and file-writing code that tinybvh's fatal-error message
  uses, frexp, wctomb): MIT, text below.
- dlmalloc by Doug Lea (malloc and free): public domain (CC0 1.0), no notice
  required.
- LLVM's libc++, libc++abi and compiler-rt (operator new and delete, and any
  compiler helper functions): Apache License 2.0 with LLVM Exceptions, whose
  exception waives the notice requirement for compiled code.

The texts are copied from emsdk 6.0.13: upstream/emscripten/LICENSE and
upstream/emscripten/system/lib/libc/musl/COPYRIGHT.
